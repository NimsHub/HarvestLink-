# HarvestLink prototype

An interactive B2B agricultural marketplace prototype with seeded local data.

Run it with Node.js 18 or later:

```powershell
npm start
```

Then open `http://127.0.0.1:4173`.

The default demo is a customer account. Select the account avatar to switch to either seller or delivery sample accounts. Prototype data is stored in the browser's local storage, so published products, bids, supply needs, and reviews remain after a refresh in the same browser.
